# Dataset Dashboard Builder — Flask

Stack: HTML, CSS, JavaScript | Python, Flask | Pandas, NumPy, Plotly, Scikit-learn | SQLite | Power BI, Tableau.

Run on Windows:
1. `py -m venv venv`
2. `venv\Scripts\Activate.ps1`
3. `python -m pip install -r requirements.txt`
4. `python app.py`
5. Open http://127.0.0.1:5000

Power BI/Tableau are the external BI/reporting layer; Plotly powers the web dashboard.
